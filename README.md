# 🏝️ Gala, Ano Tara?

An interactive Philippine tourism website that helps travelers discover 18 top destinations across Luzon, Visayas and Mindanao. Built with plain HTML, CSS and JavaScript, with no frameworks and no build step.

## ✨ Features
- 📍 **Exact location:** use browser GPS or pick from about 50 Philippine cities
- 🎯 **Smart recommendations:** "Perfect For You" scoring and "Near You" sorted by real distance (Haversine)
- 💰 **Trip budget estimator:** price ranges by travel style, mode (air, land, ferry), days and group size
- 🗺️ **Region pages:** Luzon, Visayas and Mindanao, sorted nearest-first
- 🧭 **Tour agencies:** 8 agencies with region filters and contact links
- ❤️ **Favorites** saved in the browser
- 🌗 **Day-to-night slider:** drag to switch the theme
- 📱 Responsive design

## 🚀 Run it
1. Download or clone this repo
2. Open `index.html` in your browser

For GPS to work, serve it over localhost (for example the VS Code "Live Server" extension) or use the GitHub Pages link.

## 📁 Files
| File | Purpose |
|------|---------|
| `index.html` | Page structure |
| `style.css` | Styling |
| `script.js` | Data, pages and logic |

## 🖼️ Adding photos
Each spot in `script.js` has an empty `img` field. Paste an image URL there to show a photo.

## ⚠️ Disclaimer
All prices are estimates only and may vary by season, availability and booking platform.
